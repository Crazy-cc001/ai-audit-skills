# 演示视频

所有演示均使用**合成数据**，仅用于展示「输入 → 处理 → 输出」的流程，不代表任何真实客户、项目或金额。

- 每个技能一段 12 秒演示：MP4（可下载）+ GIF（可直接预览）。
- 视频由 [`docs/demo/make_demos.py`](../demo/make_demos.py) 生成，可复现。
- 重新生成依赖：Pillow、imageio、imageio-ffmpeg、numpy。
