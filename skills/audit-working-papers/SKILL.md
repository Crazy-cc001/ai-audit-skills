# 行业协会底稿编制技能

按"读取账套 → 提取年度数据 → 解析报表 → 核对勾稽 → 填充底稿 → 明细补全 → 差异标注"七步流水线，把新纪元软件中挂接的金蝶K3账套数据与客户报表、底稿原型结合，编制十年期（如2016-2025）审计底稿。

## 一、数据源与读取通道（已验证可行）

| 数据 | 位置 | 读取方法 |
|---|---|---|
| 账套快照（加密） | `D:\新纪元\Xsjzb\Bak\MyData\CwV135_{日期}.AIS*.001` | 不可直接解（zip外壳+加密） |
| **明文数据（推荐）** | 软件挂接某年度时 → `D:\新纪元\Xsjzb\MyTemp0\`（Paradox表） | 软件运行期间用共享读复制 |
| 配置文件 | `D:\新纪元\Xsjzb\xsjcd.ini` | 含 年度=/帐套编号=/帐套名称=，可轮询检测切换 |

**关键步骤**：
1. 用户在软件中逐年挂接账套（切换年度），每次等 10 秒；
2. 用 `FileStream(FileShare.ReadWrite)` 共享读复制 MyTemp0 全部文件（约133个）到快照目录（`watch_and_capture.py` 自动轮询 ini 完成）；
3. 用 **pypxlib** 读取（预编译 dll 无需编译）：`Table(path, encoding='gbk')`，金额 BCD 字段返回 bytes 需自行转 float；
4. 核心表：Km.DB（科目字典）、Kmye.DB（年初余额，带符号：贷方为负）、Jzpz.DB（凭证分录）、P_SUM.DB（科目分月借贷汇总）、Fa_Cards.DB（固定资产卡片）。

## 二、年度数据提取（extract_year.py）

- 余额口径：**带符号统一公式** `期末 = 期初(带符号) + 借方发生 - 贷方发生`，方向由符号决定；年初余额显示取绝对值+方向列；
- 父科目汇总：**只加直接下级**的 agg（`ch[len(c):].count('.') == 1`），否则跨级重复计入（曾致净资产/往来全部虚增）；
- 校验：借贷平衡（借合计=贷合计）、P_SUM 与凭证勾稽一致、科目字典覆盖凭证代码。

## 三、客户报表解析（parse_reports.py / ba_tree.py）

- 资产负债表：KIS 导出（sheet 表页_1），左右两块，逐年验证资产总计=负债净资产总计；
- 业务活动表：**无缩进**（KIS 导出丢失），层级必须用**金额加总关系递归重建**（子项之和=父项，如 日常会议费=党委会+理事会+监事会+常务理事会+会长办公会）；解析器必须**记忆化**，否则叶子回退导致指数级死循环；
- 节标题注意：'（一）业务活动成本' 全角括号，'(三）其他不可预见支出' 半角，切分时要两者都认。

## 四、账表核对（recon_year.py）

- 资产负债表 28 项映射（民非科目：货币资金=1001+1002、应付款项=2202+2209、非限定性净资产=3101 等）；
- 损益类按**净额口径**核对：收入 = 贷方累计 − 冲减借方（红字退费/退款），费用 = 借方累计 − 红字冲减；只比净额，否则出现"假差异"（如退会费 2,500、红字税款退款 1,125.89）；
- 差异不阻断编制：金额不符处标注到对应审定表"审计说明"区，附可能原因（漏计一个月公积金、红字调整分录口径差异等）。

## 五、底稿填充原则（用户确认的规则）

1. **用户模板为准**：除目录表外全部填充；不新增表格（原型中有的表可复制，如固定资产明细表）；清残留（上一客户数据）；
2. **报表填总账、账套填明细**：资产负债表/分类表用报表数；往来/银行/净资产明细用账套逐年余额；
3. **科目全列**：一级二级科目存在即列出，无发生额填 0（银行、往来户、基金全列）；
4. **原型底稿优先**：损益审定表用协会分类项目口径（如业务活动成本 37 项、管理费用 27 项，年列值=原型），**明细层级用业务活动表树**（不是账套科目树——账套把理事会/监事会等科目归类与报表不一致）；
5. **年份命名**：十年列统一 '2016年'…'2025年'（不许用 Excel 序列数 42735 等）；模板原始年份列（如 2022年6-12月）不许改动，恢复原样填对应期数据（期间值=凭证按月按方向合计）；
6. **累计折旧符号不敏感**：净值公式 `=原价-ABS(折旧)`，正负折旧都正确；
7. **净资产结构**：一、一般基金 / 二、专用基金（下挂（一）~（四）子基金）/ 三、固定基金，**合计 = 一+二+三** = 一级数字；
8. 明细行的合计公式**只加二级行**（显式 `=C7+C16+...`），避免重复计明细。

## 六、技术坑清单（务必遵守）

- openpyxl `insert_rows` **不移动合并区域**（吞数据）→ 写数据前先 unmerge 数据区旧合并；
- 插入行后原公式行号漂移 → 重写合计/核对公式；
- 科目代码跨年漂移（如 5101.02 在 2020=专业经费、2025=党建工作经费）→ 跨年取值按**科目名称路径**匹配，更名留空；
- Excel 文件被用户打开时 save 报 PermissionError → 存临时文件，等用户关闭后替换；
- PowerShell 5.1：无 `&&`、`2>&1` 会包装 stderr；写含转义的 Python 用 Write 工具而非内联；
- 部分期间计算按方向取：收入取贷方、费用取借方；余额滚动用净发生（借-贷）。

## 七、通用性：换一家行业协会怎么用（每项目只需改配置区）

**每个新项目按顺序做 5 件事**（其余全部自动）：

| # | 事项 | 改哪里 |
|---|---|---|
| 1 | 单位名称（标题/核对表头） | 各脚本头部 `ENTITY = '××协会'` 常量 |
| 2 | 年度区间 | 各脚本 `YEARS = range(起, 止+1)` |
| 3 | 路径四件套 | 各脚本头部常量：`XSJZ_INI`（新纪元xsjcd.ini）、`MYTEMP`（MyTemp0目录）、`REPORTS`（客户报表文件夹）、`TPL`（底稿模板）／`PROTO`（原型底稿） |
| 4 | 二级分类同义词表 | `ba_tree.py` 头部 `SYN` 字典（协会分类项目名 → 业务活动表明细名，如 '维权戒惩工作'→'纪律维权工作经费'）；未匹配的分类不插明细，不影响合计 |
| 5 | 用户底稿规则 | 按 SKILL.md 第五节通用规则核对：科目全列填 0、年份 'YYYY年' 命名、模板原始年份列不擅改、净资产一/二/三结构、合计只加二级行 |

**自动适配（无需改动）**：银行/往来户明细（按账套科目树动态列出）、业务活动表层级（金额加总递归解析）、资产负债表 28 项民非科目映射（1001+1002=货币资金 等）、损益净额核对、账龄二段式判定、差异标注。

**换客户时先做三查**：① 读新客户底稿模板结构（sheet 名/行号/公式）；② 读原型底稿的分类项目口径与逐年取值来源（报表 or 账套余额）；③ 确认报表文件格式（KIS 表页_1 布局、业务活动表无缩进需金额解析）。

## 八、脚本索引（scripts/ 目录）

| 脚本 | 作用 |
|---|---|
| watch_and_capture.py | 轮询 ini 检测年度切换 → 快照 → 提取 → 核对 → 填列 |
| extract_year.py | 年度数据提取（科目/余额/凭证/汇总 → datasets.json + 总账余额表） |
| parse_reports.py | 协会报表解析（资产负债表+业务活动表 → statements.json） |
| ba_tree.py | 业务活动表层级递归解析（记忆化，金额加总判父子） |
| recon_year.py | 账表核对（BS 28 项 + 损益净额口径） |
| fill_year.py | 年度列填充（货币资金银行/往来/净资产明细，2025 加账龄表） |

| diff_notes.py | 差异说明写入审计说明区 |
