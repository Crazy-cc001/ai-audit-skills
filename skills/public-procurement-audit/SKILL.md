# 招采项目审核技能

对招采项目（政府采购、工程招标投标）进行全流程合规审核。法规依据覆盖国家、安徽省、合肥市及区县现行规定。

## 审核流程

### 1. 明确审核对象

根据用户提供的材料，确定审核类型：

| 审核对象 | 加载文件 | 核心关注点 |
|---------|---------|-----------|
| 招标文件 | `references/checklists/招标文件审核.md` | 资质条件、评分标准、技术参数、时限 |
| 投标文件 | `references/checklists/投标文件审核.md` | 串通投标迹象、文件雷同、人员交叉 |
| 评标报告 | `references/checklists/评标报告审核.md` | 评分合规、异常低价、否决投标 |
| 采购合同 | `references/checklists/合同审核.md` | 实质性条款一致、付款、追加采购 |
| 招标代理 | `references/checklists/招标代理审核.md` | 代理行为、负面清单、主体责任 |

### 2. 渐进加载检查清单

**不要一次性加载所有文件。** 根据审核对象，只 Read 对应的检查清单文件，逐项对照审核。需要法规依据时再按需加载 `references/法规速查表.md`。

### 3. 产出审核报告

使用下方模板输出结构化报告：

```markdown
# [项目名称] 审核报告

## 基本信息
- 审核日期 / 审核类型 / 项目预算 / 采购方式

## 审核发现

### 严重问题（需立即整改）
| 序号 | 问题描述 | 法规依据 | 整改建议 |
|------|---------|---------|---------|

### 一般问题（建议整改）
| 序号 | 问题描述 | 法规依据 | 整改建议 |
|------|---------|---------|---------|

## 合规性结论
- [ ] 合规  [ ] 基本合规  [ ] 不合规
```

#### 3.1 法规依据引用规范（强制）

**每一条问题的"法规依据"必须精确到文件、章节、条款，禁止使用笼统表述（如"根据相关法规""依据87号令"）。**

引用格式遵循以下层级，按优先级排列：

| 优先级 | 层级 | 示例 |
|--------|------|------|
| 1（必须） | **文件全称 + 文号/令号** | 《政府采购货物和服务招标投标管理办法》（财政部令第87号，2017年10月1日施行） |
| 2（必须） | **章节位置** | 第四章"开标、评标" → 第55条"综合评分法" |
| 3（推荐） | **条款原文** | "价格分应当采用低价优先法计算，即满足招标文件要求且投标价格最低的投标报价为评标基准价" |
| 4（可选） | **补充说明** | 解释条款性质（强制性/禁止性/授权性）、例外情形等 |

**正确示例：**
```
《政府采购货物和服务招标投标管理办法》
（财政部令第87号，2017年10月1日施行）
第四章"开标、评标" → 第55条第二款
原文："价格分应当采用低价优先法计算……"
```

**错误示例（禁止）：**
- ❌ "违反87号令第55条"（缺少文件全称、章节位置）
- ❌ "不符合相关法规要求"（未指明具体法规）
- ❌ "违反《招标投标法》"（未指明章节条款）

**审核报告末尾须增加"附件：引用法规条文索引"表格**，汇总报告中引用的每一部法规，包含：序号、法规全称、文号/令号、施行日期、涉及章节条款、核心内容摘要。

## 脚本工具

以下 Python 脚本位于 `scripts/` 目录，用于自动化合规检查：

| 脚本 | 用途 | 用法 |
|------|------|------|
| `scripts/bid_metadata_check.py` | 投标文件元数据分析：提取创建者/修改者/MD5哈希，检测同一人编制迹象 | `python scripts/bid_metadata_check.py <投标文件目录> [输出.json]` |
| `scripts/abnormal_price_check.py` | 异常低价检测：支持安徽省级和合肥2026版两套标准 | `python scripts/abnormal_price_check.py <控制价> <类型> <报价列表>` 或用 JSON 文件 |
| `scripts/timeline_check.py` | 时间节点合规检查：发售期、截标、中标通知书、合同签订等9项 | `python scripts/timeline_check.py <事件.json>` |
| `scripts/scoring_check.py` | 评标评分异常检测：客观分一致性、主观分Z-score畸高畸低 | `python scripts/scoring_check.py <评分数据.json>` |

脚本返回码：发现违规项时 exit(1)，合规时 exit(0)，可集成到 CI/自动化流程中。

## 文档处理

审核过程中遇到不可直接读取的文档：

| 格式 | 处理方法 |
|------|---------|
| PDF | Read 工具直接读取（支持文本型PDF）；扫描件需 Read 图片页后视觉提取 |
| .docx/.doc | PowerShell 调用 Word COM：`$word.Documents.Open(...).Content.Text` |
| .CHM | PowerShell：`hh -decompile <输出目录> <chm路径>` |
| 图片（扫描件截图） | Read 工具读取图片，视觉能力提取文字表格 |
