# 法规体系速查表

按效力层级整理的政府采购与工程招标投标法规体系。审核时按需查找具体法条。

## 一、国家层面（法律→法规→规章→规范性文件）

### 法律
| 文件 | 核心内容 |
|------|---------|
| 《政府采购法》（2003版） | 政府采购基本制度：适用范围、采购方式、程序、合同、质疑投诉、法律责任 |
| 《招标投标法》 | 工程招标基本制度 |

### 行政法规
| 文件 | 核心内容 |
|------|---------|
| 政府采购法实施条例 | 8类差别待遇/歧视待遇（第20条）、视为/属于串通投标（第37/74条）、时限 |
| 招标投标法实施条例 | 招标程序、评标委员会、时限 |
| 保障中小企业款项支付条例（728号令） | 30日付款、最长≤60日、每日万分之五逾期利息、禁止强制审计结算 |

### 部门规章
| 文件 | 核心内容 |
|------|---------|
| 87号令（货物服务招标投标） | 招标程序、评标方法（最低评标价法/综合评分法）、价格分权重、异常低价 |
| 74号令（非招标采购方式） | 竞争性谈判、单一来源（公示≥5工作日）、询价 |
| 94号令（质疑投诉） | 质疑7工作日 → 答复7工作日 → 投诉15工作日 |
| 101号令（信息发布） | 省级以上财政部门指定媒体、1个工作日内发布 |
| 102号令（政府购买服务） | 合同≤1年（最长≤3年）、禁止转包、公益一类事业单位不得作为主体 |
| 110号令（框架协议） | 封闭式为主、淘汰率≥20%、货物≤1年/服务≤2年 |
| 涉密采购暂行办法（财库〔2019〕39号） | 定密审批、绝密自行组织、供应商3年无不良记录 |
| 发改委16号令（必须招标工程项目） | 施工≥400万/货物≥200万/服务≥100万 |
| 七部委12号令（评标委员会和评标方法） | 评标委员会组成、回避、两种评标方法 |

### 规范性文件
| 文件 | 核心内容 |
|------|---------|

| 评审专家管理办法（财库〔2016〕198号） | 随机抽取、不满70周岁、回避情形、违规罚2千-5万 |

| 公平竞争审查规则（2024年第16号令） | 禁止指定代理机构、抽签摇号、本地缴税社保等条件 |
