# 招采项目审计八大重点

基于安徽省招标采购培训资料和审计实践总结的全流程审计框架。

## 八大重点总览

| 序号 | 审计重点 | 核心审查内容 |
|------|---------|-------------|
| 1 | **规避招标、虚假招标** | 应招未招、化整为零、肢解发包、先建后招、明招暗定、虚构涉密/应急项目 |
| 2 | **建设和招标程序合法合规性** | 项目审批/核准/备案、资金落实、进场交易、招标方式合规 |
| 3 | **招标采购文件审查主体责任** | 资质条件是否虚高、评分标准是否合理、是否含歧视性/排他性条款 |
| 4 | **评标报告审查主体责任** | 评分一致性、异常低价处理、否决投标依据、中标候选人合规 |
| 5 | **招标采购内控制度及执行** | 制度健全性、分事行权分岗设权、"三重一大"决策程序 |
| 6 | **合同履行落实** | 阴阳合同、实质性条款变更、转包/违法分包、关键人员变更 |
| 7 | **投标人和承包人审查** | 串通投标、挂靠出借资质、人员"挂证"、虚假材料 |
| 8 | **异议投诉处理** | 异议答复时限、投诉处理程序、是否暂停采购活动 |

## 1. 规避招标、虚假招标

### 必须招标三要素（国家发改委16号令）
1. **项目类型**：工程建设项目（新建、改建、扩建及相关的装修、拆除、修缮）
2. **资金来源**：全部或部分使用国有资金投资或国家融资（含国有企事业单位资金占控股或主导地位）
3. **规模标准**：施工≥400万 / 货物≥200万 / 服务≥100万（同一立项批文+同一项目性质+同一采购人须合并计算）

### 常见规避招标情形
- 母子公司/入股公司投资项目直接发包
- 同一项目划分多个标段规避合并计算
- 追加项目规避招标（技术上紧密相连不可分割的除外）
- 招商引资项目规避招标
- EPC总承包中单部分达标而不招标（施工400万/货物200万/服务100万，任一项达标即整体必须招标）
- 暂估价达必须招标标准不招标直接发包
- 以会议纪要/集体决策名义转为非招标方式
- 虚构涉密项目或应急项目规避招标

### "三清单"共享核查比对机制（安徽107号文）
- 公共资源交易项目清单 ↔ 审批核准备案项目清单 ↔ 施工许可证（开工备案）项目清单
- 从项目名称、投资规模、建设单位、招标时间、发包方式、中标企业、施工许可证办理时间等关联关系常态化核查

## 2. 建设和招标程序合法合规性

- 项目是否经审批/核准/备案？
- 资金是否落实？（政府投资项目不得由施工单位垫资建设）
- 是否按规定进入公共资源交易平台？
- 招标方式是否合规？（公开招标数额以上转非招标方式须经批准）
- 合肥市交易目录进场门槛：
  - 区级：施工≥1000万/货物服务≥400万 → 市级平台
  - 县级：施工≥1亿/货物≥3000万/服务≥1000万 → 市级平台

## 3. 招标采购文件审查主体责任

详见 `checklists/招标文件审核.md`。重点：
- 资质条件是否虚高
- 是否含16类禁止性初步评审指标
- 评分因素是否量化
- 业绩规模指标是否超过项目对应指标的70%

## 4. 评标报告审查主体责任

详见 `checklists/评标报告审核.md`。重点：
- 客观评分不一致、主观分畸高畸低
- 是否按异常低价制度进行评审
- 否决投标是否有明确依据
- 中标候选人公示内容是否完整

## 5. 招标采购内控制度及执行

- 是否建立集体研究、合法合规性审查议事机制？
- 是否分事行权、分岗设权、分级授权？
- "评定分离"项目是否纳入"三重一大"审议？
- 国有企业招标采购制度是否分三类管理：（1）依法必须招标执行国家法规；（2）非招标竞争方式参照74号令；（3）"三重一大"程序直接发包项目
- 有无以领导签字代替招标程序、内控制度成空文的情况？

## 6. 合同履行落实

详见 `checklists/合同审核.md`。重点：
- 阴阳合同（背离实质性内容的协议）
- 关键岗位人员变更（国有资金项目须经住建委和招投标监督部门同意，变更后资格业绩不低于原人员）
- 转包/违法分包

## 7. 投标人和承包人审查

详见 `checklists/投标文件审核.md`。重点：
- 串通投标（6种视为+7种属于+10大关注情形）
- 提供虚假资质/业绩/人员材料 → 采购金额5‰-10‰罚款+1-3年禁入
- 挂靠出借资质、人员"挂证"

## 8. 异议投诉处理

**时限要求：**
- 资格预审文件异议：申请文件提交截止2日前提出 → 3日内答复
- 招标文件异议：投标截止10日前提出 → 3日内答复
- 开标异议：现场提出 → 当场答复
- 评审结果异议：公示期内（≥3日）提出 → 3日内答复（答复前暂停招投标活动）
- 投诉：知道或应知之日起10日内提起 → 3个工作日内审查 → 30个工作日内处理决定

**常见投诉处理问题：**
- 评审委员会评审错误（应否未否、不应否随意否）
- 客观评审分数错误（业绩/奖项/财务打分）
- 第一中标候选人弄虚作假
- 项目经理有在建项目或同时中两个标
- 项目经理变更未在投标文件中附变更材料（按招标文件约定处理）
