# 招标代理活动审核清单

**法规依据：** DB34T5013-2025（安徽省招标代理规程）、合公法〔2020〕46号（合肥负面清单45项）、皖发改公管〔2024〕699号（负面行为清单23项+主体责任清单13项）、合公代〔2025〕43号（综合评价管理办法）。

## 一、代理机构基本条件

- [ ] 是否依法设立、具备编制招标文件和组织开展评标的能力？
- [ ] 是否与行政机关存在隶属或利益关系？
- [ ] 是否在交易中心实名登记并承诺信息真实性？
- [ ] 从业人员是否与机构签订劳动合同、由本单位缴纳社保？
- [ ] 是否实行项目负责人制？

## 二、承揽与委托

- [ ] 是否签订书面委托合同？（未签不得开展代理活动）
- [ ] 是否在委托范围内执业？
- [ ] 是否存在行贿、回扣、输送不正当利益承揽业务？【107号文】
- [ ] 是否明知委托事项违法仍代理？
- [ ] 未经招标人同意是否转让代理业务？

## 三、招标过程行为

### 3.1 禁止行为（高频违规）

- [ ] **是否在所代理项目投标、代理投标或为投标人提供咨询？**（严禁）
- [ ] **是否干预影响评标过程和结果？**（严禁）
- [ ] **是否与招标人、投标人、评标专家、平台串通？**（严重违规，直接C级）
- [ ] 是否向评标专家以外人员发放评审费？（严禁）
- [ ] 是否擅自修改/伪造/变造/隐匿招标投标文件及结果文件？
- [ ] 采购代理机构人员是否参加了所代理项目的评标？（禁止）
- [ ] 是否泄露应保密的信息（潜在投标人、评审专家名单、评审情况等）？

### 3.2 费用与保证金

- [ ] 是否收取投标保证金？（安徽政府采购：免收，收取即违法违规）
- [ ] 是否收取采购文件工本费？（安徽：免收）
- [ ] 是否巧立名目收取无法律依据的保证金或费用？
- [ ] 是否以营利为目的收取高额文件费？
- [ ] 是否按约定标准收取代理费？有无额外向中标人索取费用？
- [ ] 收费是否开发票？有无以个人名义代收？

### 3.3 信息与程序

- [ ] 是否依法及时完整在指定媒体发布信息？
- [ ] 是否向不同投标人提供差别信息？
- [ ] 是否对招标人违法要求无原则附和、不抵制？
- [ ] 发现评标专家违法是否及时向监管部门报告？
- [ ] 发现围标串标等违法违规情形是否及时制止并书面报告？

## 四、档案管理

- [ ] 是否妥善归档（含音视频、交易数据）？
- [ ] 是否及时向招标人移交全套档案？
- [ ] 是否存在伪造、变造、隐匿、销毁档案的行为？
- [ ] 电子档案是否在合同签订后7个工作日内在线提交归档？

## 五、代理机构综合评价（合肥合公代〔2025〕43号）

- 得分 = 基本情况分 + 服务质量与履约行为分 + 良好行为分
- 等级：AAA（前30%）、AA（30%-60%）、A（60%-90%）、B（后10%）
- **直接评C级的行为：** 行贿回扣、虚假招标、指使纵容默许串标、与相关人员恶意串通、擅自修改/隐匿/销毁文件数据、综合评价弄虚作假
- B级及以下：列入重点监管、约谈负责人；C级：责令整改
- 鼓励国有资金项目选高等级代理机构（选低等级的，风险由项目单位自担）

## 六、合肥市政府采购负面清单（45项）核心速记

**资格条件类禁止（14项）：** 要求投标报名；电子采购文件收费；所有制/组织形式/所在地限制；规模条件限制（注册资本/营收/从业人员等）；特定行政区域或行业业绩奖项；已取消或非强制资质；行业协会证书/会员/奖项；生产厂家授权（进口除外）；三库（备选/名录/资格库）；指定购买软件；要求设分支机构；以人员从业年限作资格条件；未要求提供信用记录。

**采购需求类禁止（15项）：** 未落实中小企业/监狱企业/残疾人政策；未经核准采购进口；设定最低限价；指定专利/商标/品牌/供应商；指定检测机构；不合理差别待遇；要求赠品回扣；非强制资质作实质性要求；未载明核心产品；随意要求提供样品；评审后通过样品检测/考察改变结果；实质性要求未醒目标明；信息发布不及时；**投标保证金超预算2%、履约保证金超合同金额10%。**

**评标办法类禁止（16项）：** 谈判/询价未按最低价定标；标准统一货物服务不采用最低评标价法；综合评分价格权重低于下限（货物30%/服务10%）；磋商价格分超范围；未用低价优先法；资格条件/规模条件作评审因素；未列明指标作评审因素；无关业绩资信荣誉作评分条件；特定区域/行业业绩奖项加分；指定品牌加分；评审因素未量化；设定去掉最高最低报价。

## 七、招标人主体责任清单（13项）

| 阶段 | 关键责任 |
|------|---------|
| 招标准备 | 履行审批核准/资金落实/条件具备；不得肢解发包/化整为零/设不合理暂估价/虚构涉密应急项目规避招标；招标计划提前≥30日发布；建立集体研究议事机制 |
| 招标实施 | 审查代理编制的文件/使用示范文本；不得设定最低投标限价；投标人少于3个不得开标；审查评标报告（客观分/畸高畸低/异常低价/否决合规性）；收到评标报告3日内公示≥3日；异议处理时限答复、答复前暂停；15日内提交书面报告 |
| 履约阶段 | 30日内签合同且条款须与招标文件和投标文件一致；健全履约管理（关键人员到岗/变更/转包违法分包报告）；档案齐全完整不得篡改损毁伪造 |
