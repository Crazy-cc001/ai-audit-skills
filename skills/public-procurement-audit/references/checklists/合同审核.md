# 合同审核清单

**法规依据：** 政府采购法第46-49条、实施条例第48-50条、保障中小企业款项支付条例（728号令）、安徽省相关规定。

## 一、合同签订

- [ ] 合同是否在中标/成交通知书发出之日起30日内签订？【法第46条】
- [ ] 合同是否在签订后2个工作日内公告（涉密除外）？【实施条例第50条】
- [ ] 合同主要条款是否与招标文件和中标人投标文件一致？【安徽301号令】
- [ ] **是否存在背离合同实质性内容的协议（阴阳合同）？** → 违反将处中标金额5‰-10‰罚款【招标投标法第46条/实施条例第57条】
- [ ] 是否存在中标后向中标人提出不合理要求作为签约条件？
- [ ] 合同变更后是否在2个工作日内公告变更信息？【财办库〔2023〕243号】

## 二、合同内容

- [ ] 是否包含：标的、质量、数量、履行期限地点方式、价款、付款进度、支付方式、验收交付标准、质量保修范围期限、违约责任与争议解决？
- [ ] 是否采用示范文本？
- [ ] 专用条款是否明确：工程量调整办法、人工费材料价调整、结算方式、质保金、缺陷责任期？
- [ ] **是否强制以审计结果作为结算依据？**（禁止，合同另有约定除外）【728号令】
- [ ] 是否以法定代表人变更、内部流程、等待竣工验收批复/决算审计等为由设置不合理的付款条件？

## 三、价格与付款

- [ ] 付款期限是否明确？（安徽：收到发票后7个工作日内支付，不得以审计、机构变动等为由延迟）
- [ ] 是否约定预付款？（中小企业合同预付款比例不低于40%、不高于70%）【皖财购[2022]556号】
- [ ] 预付款是否在合同/担保生效且具备实施条件后5个工作日内支付？
- [ ] 逾期付款是否约定利息？（无约定按每日万分之五）【728号令】
- [ ] 是否明确材料价格风险范围和调整办法？（未约定的：价差5%以内施工方承担，超5%建设方承担）【507号文】
- [ ] 合同是否包含"无限风险、所有风险"等被禁止的计价风险条款？

## 四、追加与变更

- [ ] 追加采购是否超过原合同金额10%？【法第49条】
- [ ] 追加采购是否改变了合同其他条款？
- [ ] 是否存在擅自变更、中止、终止合同的情况？
- [ ] EPC合同约定的价格调整情形是否完备？（仅约定"建设单位原因和不可抗力"调价可能被审计认定为不合理）

## 五、履约与验收

- [ ] 履约保证金是否超过规定上限？（安徽货物服务≤2.5%、工程≤10%）【皖财购[2022]556号】
- [ ] 是否允许供应商自主选择保证金形式（现金/支票/保函/保险）？
- [ ] 是否已缴纳履约保证金的同时又预留质量保证金？（禁止）
- [ ] 质量保证金是否超过工程价款结算总额3%？缺陷责任期是否超过2年？
- [ ] 验收标准是否明确？（货物：出厂/到货/安装/配套；服务：分阶段考核；工程：按行业标准）
- [ ] 验收是否在规定时限内完成？（安徽：收到验收申请后5个工作日内组织验收）
- [ ] 公共服务项目验收结果是否向社会公告？
- [ ] 是否因验收不合格依法处理？（验收结果与资金支付及履约保证金返还挂钩）

## 六、转包与分包

- [ ] 是否存在转包行为？（全部转给他人、肢解后分包、未派驻管理人员等情形）
- [ ] 分包是否经采购人同意？
- [ ] 分包单位是否具备相应资质？
- [ ] 是否存在再次分包或劳务再分包？
- [ ] 主体结构施工是否被分包？（钢结构工程除外）
- [ ] 关键岗位人员（项目经理、技术负责人、质量/安全负责人等）是否擅自变更？变更后资格业绩是否不低于原人员？
