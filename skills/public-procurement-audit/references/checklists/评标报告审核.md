# 评标报告审核清单

**法规依据：** 87号令第64条（重新评审4种情形）、建市函〔2020〕1073号（异常低价）、合公业〔2026〕30号（合肥2026版异常低价公式）。

## 一、评分合规性

- [ ] 是否修改了招标文件规定的评分标准或使用了招标文件未规定的方法？
- [ ] **客观分是否一致？**（同一客观项，不同评委给同一投标人的打分应完全相同）→ 不一致可重新评审【87号令第64条】
- [ ] **主观分是否畸高畸低？**（某评委给特定投标人的分数偏离平均分超过1.8个标准差）→ 可重新评审
- [ ] 分值汇总计算是否正确？
- [ ] 分项评分是否超出评分标准范围？
- [ ] 评委之间打分偏差是否过大？（同一投标人的主观分偏差超过20%）

> **脚本辅助：** `scripts/scoring_check.py` 可自动检测客观分不一致和主观分Z-score异常。

## 二、异常低价评审

### 安徽省标准（1073号文，通用标准）

| 项目类型 | 异常低价线（低于招标控制价） |
|---------|------------------------|
| 房屋建筑 | 90% |
| 轨道交通 | 88% |
| 市政基础设施 | 85% |

### 合肥市2026版标准（合公业〔2026〕30号，2026.5.20起施行）

**施工总承包 — 动态公式：**
```
异常低价 = 最高投标限价 × 静态指标 × Y1 + (投标报价平均值 − 样本标准差) × Y2
```
- 静态指标：房建88%、轨道交通85%、市政80%
- Y1 + Y2 = 100%，30% ≤ Y ≤ 70%

**其他项目（工程总承包、专业承包等）— 低于以下任一：**
- 投标报价算术平均值 × 50%
- 次低报价 × 50%
- 最高投标限价 × 45%（工程总承包为合同估算价 × 45%）
- 评标委员会专业判断

> **脚本辅助：** `scripts/abnormal_price_check.py` 支持省标准一键检测，合肥动态公式需提供完整报价数据。

### 评审程序要求

- [ ] 触发异常低价后，是否要求投标人书面澄清说明并提供证明材料？
- [ ] 评标委员会是否对合同履行能力及质量安全风险进行了全面评估？
- [ ] 评估结果是否作为评标结果附件提交招标人？
- [ ] 不能有效澄清或认定存在风险的投标是否被否决？
- [ ] **以下理由不得作为异常低价说明依据：** 机械材料自有或闲置、自有弃土场土源、人员闲置、亏本让利、企业市场拓展或品牌宣传、降低或改变原设计方案/技术工艺/施工标准、类似项目业绩

## 三、否决投标合规性

- [ ] 否决投标的理由是否符合招标文件规定和法律法规？（必须有明确依据：法律规定条款、招标文件明确约定条款、未实质性响应）
- [ ] 有无应当否决但未否决的投标？
- [ ] 有无随意否决投标的情况？（以非资格条件的证书如三体系认证否决属典型错误）
- [ ] 是否依法要求投标人对疑问进行澄清、说明？
- [ ] 投标文件被否决的原因是否向投标人公开？
- [ ] 否决投标是否以装订、纸张、明显文字错误等非实质性原因为由？（禁止）
- [ ] 实质性内容界定是否准确？（价款、质量、工期、投标有效期、资格条件、形式评审要求等）

## 四、中标候选人审核

- [ ] 推荐的中标候选人是否符合资格条件？
- [ ] 信用记录是否良好？（是否查询了"信用中国"、中国政府采购网）→ 信用记录须随采购文件一并保存
- [ ] 保函是否真实有效？
- [ ] 中小企业声明函是否真实？（如适用）
- [ ] 项目经理是否有在建项目或同时在两个项目任职？
- [ ] 项目班子社保是否符合要求？
- [ ] 中标候选人数量是否符合规定？（1-3名并排序）
- [ ] 国有资金控股项目是否确定排名第一的中标候选人为中标人？

## 五、报告形式审核

- [ ] 评标报告内容是否完整？
- [ ] 是否有计算错误或遗漏？
- [ ] 评委签字是否齐全？
- [ ] 不同意见是否记录并说明理由？
- [ ] 是否全程录音录像并存档？
- [ ] 评标专家名单在中标结果公告前是否保密？
- [ ] 评标委员会组成是否合规？（5人以上单数，专家≥2/3；预算1000万以上/技术复杂/社会影响大项目7人以上单数）
- [ ] 评审专家是否从省级以上财政部门专家库随机抽取？
- [ ] 是否存在应回避未回避的情况？（前3年内与供应商有劳动关系/董事监事/控股股东/近亲属等）
