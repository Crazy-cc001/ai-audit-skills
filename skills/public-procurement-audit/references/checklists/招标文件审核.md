# 招标文件审核清单

逐项检查招标文件的合规性。重点关注资质条件虚高、歧视性条款、评分标准不合理三大问题。

## 一、资质条件设置（最高频问题区）

**核心原则：资质条件须与项目实际需要匹配，不得设置任何形式的差别待遇或歧视待遇。** 法规依据：《政府采购法实施条例》第20条（8类歧视待遇）、87号令第17条。

### 1.1 禁止设置的歧视性条件

- [ ] 是否将特定行政区域或行业的业绩、奖项作为门槛条件？
- [ ] 是否将注册资本、资产总额、营业收入、从业人员、利润、纳税额等规模条件作为资格要求或评审因素？
- [ ] 是否对不同所有制形式、注册地的投标人设置不同标准？
- [ ] 是否要求投标人在本地注册、设立分公司或要求法定代表人必须到场开标？
- [ ] 是否限定指定专利、商标、品牌或供应商？
- [ ] 是否以特定行政区域或行业的业绩、奖项作为加分条件？
- [ ] 是否将已取消或非强制的资质/资格/认证/目录作为资格条件？
- [ ] 是否将行业协会商会的证书/会员/奖项作为资格条件？
- [ ] 是否以营业执照经营范围作为投标/加分/中标条件？
- [ ] 是否将生产厂家授权/承诺/证明/背书作为资格条件（进口货物除外）？
- [ ] 是否设置"备选库/名录库/资格库"作为参与条件？

### 1.2 资质等级合理性

- [ ] 企业资质等级是否高于项目实际需要？（例：单跨45米工业厂房要求总承包一级+钢结构一级即属多余）
- [ ] 人员资格要求是否与项目规模匹配？
- [ ] 业绩要求是否合理？（作为资格条件时同类合同一般不超过2个，规模指标不超过项目对应指标的70%）
- [ ] 对除特大型或技术特别复杂以外的房建市政工程，是否设置了企业业绩/奖项作为资格或加分条件？（安徽禁止）
- [ ] 是否要求总承包企业同时具备承包范围内专业承包资质？（钢结构分部超估算价50%的除外）
- [ ] 单一房建或市政总承包招标是否要求同时具备两个及以上类别总承包资质？

---

## 二、技术参数设置

- [ ] 技术参数是否指向特定供应商或产品？
- [ ] 是否使用"知名品牌""一线品牌""同档次"等模糊表述？
- [ ] 技术指标是否可量化、可验证？
- [ ] 客观但不可量化的指标是否作为实质性要求而非评分项？
- [ ] 是否指定检测机构或限定检测报告时间区间？
- [ ] 是否要求提供样品？（一般不得要求，特殊情况除外，须明确评审方法标准）

---

## 三、评分标准设置

**法规依据：** 87号令第55条。

### 3.1 分值权重

- [ ] 货物项目价格分权重是否 ≥30%？服务项目是否 ≥10%？
- [ ] 竞争性磋商：货物价格分是否在30%-60%？服务是否在10%-30%？
- [ ] 价格分是否采用低价优先法：`得分 = (基准价 / 投标报价) × 100`？
- [ ] 是否违规去掉最高价和最低价？（禁止）
- [ ] 业绩分值是否 ≤10分？奖项荣誉分值是否 ≤10分？（合肥2026：商务+技术总分 ≤15分，技术文件 ≤5分）
- [ ] 施工组织设计分值是否 ≤5分？

### 3.2 评审因素设置

- [ ] 评分因素是否细化量化并与采购需求对应？（禁止使用"优良一般"等模糊分级）
- [ ] 资格条件是否被设置为评审因素？（禁止）
- [ ] 是否将规模条件（注册资本、营收等）作为评审因素？（禁止）
- [ ] 是否将需求中未列明的技术参数/商务条件作为评审因素？
- [ ] 评审因素是否与项目特点实际需要相适应、与合同履行相关？
- [ ] 是否以装订、纸张、排序等非实质性格式问题作为评分或否决条件？（禁止）

---

## 四、时限要求

- [ ] 采购意向公开是否在采购活动开始前 ≥30日？（安徽：不足30日须报同级财政部门同意）
- [ ] 招标计划是否在招标公告前 ≥30日发布？（依法必须招标的房建市政项目）
- [ ] 招标文件发售期是否 ≥5个工作日？
- [ ] 招标文件发出至投标截止是否 ≥20日？
- [ ] 澄清修改是否在投标截止至少15日前发出？不足15日是否顺延截止时间？
- [ ] 资格预审公告期是否 ≥5个工作日？
- [ ] 竞争性磋商文件发出至首次响应截止是否 ≥10日？
- [ ] 竞争性谈判/询价文件发出至响应截止是否 ≥3个工作日？

---

## 五、其他合规检查

### 5.1 信息公开与文件编制

- [ ] 预算金额是否在招标文件中公开？（必须）
- [ ] 是否设置最低限价？（禁止，可设最高限价）
- [ ] 实质性要求是否以"★"号醒目标明？
- [ ] 货物类非单一产品是否载明核心产品？
- [ ] 否决性条款是否集中载明？
- [ ] 是否落实中小企业/监狱企业/残疾人就业/节能环保/绿色采购等政府采购政策？

### 5.2 工程招标特别检查（安徽省规定）

- [ ] 政府投资项目是否要求施工单位垫资建设？（禁止）【安徽301号令】
- [ ] 是否将应一个承包单位完成的工程肢解发包？（禁止）
- [ ] 招标控制价组价文件是否与招标文件同时发布？（禁止违规上浮或下调）
- [ ] 是否明确材料价格风险范围和调整办法？（禁止"无限风险、所有风险"语句）【507号文】
- [ ] 是否载明工程款支付担保（合同额8%-10%）？【54号文】
- [ ] 工程量清单及最高投标限价是否随招标公告同步发布？（合肥2026要求）

### 5.3 中小企业扶持

- [ ] 200万以下货物服务、400万以下工程是否专门面向中小企业？【46号文】
- [ ] 超过以上限额的，是否预留 ≥40%（安徽标准）面向中小企业？预留份额中小微企业占比是否 ≥60%（货物服务≥70%）？
- [ ] 未预留份额项目是否对小微企业报价给予10%-20%（安徽标准）价格扣除？

### 5.4 保证金与费用（安徽特色）

- [ ] 是否收取了投标保证金？（安徽政府采购：一律免收，收取即属违法违规）【皖财购[2022]556号】
- [ ] 是否收取了采购文件工本费？（安徽：免收）
- [ ] 工程类项目：投标保证金是否超过估算价2%或80万上限？
- [ ] 是否限定保证金只能以现金缴纳？（必须接受保函等非现金形式）
- [ ] 是否同时收取履约保证金和质量保证金？（禁止）
- [ ] 质量保证金是否超过工程价款结算总额3%？缺陷责任期是否超过2年？
