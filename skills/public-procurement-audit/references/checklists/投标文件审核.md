# 投标文件审核清单（串通投标检测）

**法规依据：** 87号令第37条（视为串通投标6种情形）、实施条例第74条（恶意串通7种情形）、皖发改公管〔2024〕107号（八部门反串通投标）。

## 一、文件异常一致性检查

- [ ] 不同投标文件的文字字体、字号、加粗、对齐方式等非标准格式是否完全一致？
- [ ] 技术方案、施工组织设计等主观性强的部分是否大面积雷同？
- [ ] 不同投标文件中是否出现相同的错别字、计算错误、标点错误？
- [ ] 投标文件是否异常一致或报价呈规律性差异？【87号令第37条(4)】
- [ ] 投标文件是否相互混装？【87号令第37条(5)】
- [ ] 不同投标文件是否由同一单位或个人编制？【87号令第37条(1)】

> **脚本辅助：** 文件元数据分析和文本相似度比对可使用 `scripts/bid_metadata_check.py`。

## 二、人员关联检查

- [ ] 不同投标人的法定代表人、股东、董事、监事等高管是否存在交叉或相同？
- [ ] 不同投标单位注册地址、联系电话、邮箱是否相同？
- [ ] 项目管理成员（项目经理、技术负责人）是否为同一人？【87号令第37条(3)】
- [ ] 授权代表或投标事宜办理人是否相同？【87号令第37条(2)】
- [ ] 同一单位负责人或存在直接控股、管理关系的供应商是否参加同一合同项下采购？【实施条例第18条】
- [ ] 不同投标人是否委托同一单位或个人办理投标事宜？

## 三、技术痕迹检查

- [ ] 不同投标文件的创建者、最后保存者等元数据是否相同？（用脚本自动检测）
- [ ] 上传文件的电脑硬盘序列号（HDD）、网卡MAC地址是否相同？
- [ ] 不同投标文件是否从同一IP地址上传？
- [ ] 投标文件制作机器码、创建标识码、造价锁号是否相同？（合肥评标系统自动比对）
- [ ] 投标保证金是否从同一账户转出？【87号令第37条(6)】
- [ ] 联系人电话是否相同？

## 四、投标行为异常检查

- [ ] 是否存在"陪标专业户"（中标率异常低但频繁投标）？【107号文】
- [ ] 是否存在"标王"（中标率异常高，同一企业频繁在同一单位或区域中标）？
- [ ] 是否存在经常性抱团投标的串标"合伙人"？
- [ ] 是否提供虚假资质、业绩或人员材料？【法第77条】
- [ ] 项目经理是否在多个项目同时任职？（注册建造师不得同时在两个及以上项目担任项目负责人）
- [ ] 下载招标文件的十几家，最终只有3-5家投标？

## 五、串通投标法定认定标准

### 视为串通投标（6种情形，87号令第37条）

1. 不同投标人的投标文件由同一单位或个人编制
2. 不同投标人委托同一单位或个人办理投标事宜
3. 不同投标人的项目管理成员或联系人为同一人
4. 不同投标人的投标文件异常一致或报价呈规律性差异
5. 不同投标人的投标文件相互混装
6. 不同投标人的投标保证金从同一账户转出

### 属于恶意串通（7种情形，实施条例第74条）

1. 协商投标报价等实质性内容
2. 约定中标人
3. 约定部分投标人放弃投标或中标
4. 为谋取中标排斥其他投标人而采取联合行动
5. 同一集团/协会/商会成员按组织要求协同投标
6. 投标人间为谋取中标的其他联合行动
7. 招标人/代理机构授意撤换修改投标文件、明示暗示压低抬高报价

## 六、围标串标十大关注情形（审计实战经验）

1. 下载招标文件十几家 → 最终仅3-5家投标
2. 中标人评分接近满分 → 其他均及格分
3. 报价接近控制价或呈规律性分布
4. 中标人资料完整 → 其他明显不完整
5. 多家企业长期一起投标、人员混用、委托代理人同一人
6. 招标人评委打分畸高畸低
7. 中标后拖延公示、第一名弃标改选第二名
8. 同一企业频繁在同一单位或同一区域中标
9. 中标人主要负责人与招标人主要负责人存在关联关系
10. 不同投标人背后控制人为同一人

## 七、转包与违法分包认定

### 转包认定（建市规〔2019〕1号第8条）

- 全部工程转给他人（含母公司转子公司）
- 肢解后以分包名义转包
- 未派驻项目负责人/技术负责人/质量安全负责人，或派驻人员未签劳动合同、未缴社保
- 未对施工活动进行组织管理
- 主要建筑材料/构配件/设备采购交给他人
- 无工程款收付关系
- 联合体一方不施工不管理仅收取管理费

### 违法分包认定

- 分包给个人或不具备相应资质单位
- 将主体结构施工分包（钢结构工程除外）
- 专业分包再分包非劳务部分
- 劳务再分包
- 劳务承包人计取主要材料款和大型机械设备费
