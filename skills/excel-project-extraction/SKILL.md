# Excel项目批量提取技能

按"Excel解析筛选 → 源目录检索复制 → 批量提取投标人信息 → 汇总输出 → 去重校验"五步流水线，把带填充色标记的抽查清单转化为每项目一份的《投标人信息汇总表》。

PDF提取部分复用 `pdf信息提取` 技能的四步流水线（关键词页 → 转Word → 清洗 → 汇总Excel，含自动兜底），本技能不重复实现。

## 流水线

```
抽查Excel(带填充色标记)
  │ 步骤1 screen_excel.py   识别标记行 → 机构/序号区间/编号区间筛选 → 匹配清单.json
  ▼
步骤2~4 batch_run.py       按编号在源目录匹配文件夹并复制 → 逐项目跑pdf流水线 → 重命名输出汇总表
  ▼
步骤5 dedup_check.py       单列查重: 报告 / 颜色标记 / 生成去重副本
```

## 前置条件

- Python 3.8+；依赖：`pandas openpyxl`（本技能）+ `pdfplumber PyPDF2 pdf2docx python-docx`（pdf流水线）
  - 一键安装：运行本技能目录下的 `install.ps1`
- 执行约定：始终用 `python -X utf8` 运行脚本；路径用双引号包住；如实报告失败清单。

## 步骤1：Excel解析筛选

```powershell
python -X utf8 "<技能目录>\scripts\screen_excel.py" --excel "<抽查Excel路径>" [参数...]
```

| 参数 | 说明 |
|------|------|
| --excel | 必填。目标Excel路径 |
| --orgs | 机构列表，逗号分隔，对应sheet名；默认 `市交易中心`；`ALL`=全部sheet |
| --colors | 填充色hex，逗号分隔；默认 `FFFFFF00,FF92D050`（黄、绿） |
| --seq-start / --seq-end | 序号区间（含）；可只给一端 |
| --code-start / --code-end | 项目编号区间（含，字符串比较）；可只给一端 |
| --out | 匹配清单JSON路径；默认Excel同目录下 `匹配清单.json` |

规则：一行中任意单元格为实色填充且颜色在 --colors 内即视为标记行；序号区间与编号区间同时给出时取交集。表格需含「序号」「项目编号」列（编号列必选，其余可选）。

## 步骤2~4：检索复制 + 批量提取 + 汇总输出

```powershell
python -X utf8 "<技能目录>\scripts\batch_run.py" --list "<匹配清单.json>" --source-dir "<源文件根目录>" --dest-dir "<项目复制目录>" --summary-dir "<汇总表输出目录>" [参数...]
```

| 参数 | 说明 |
|------|------|
| --list | 必填。步骤1的匹配清单JSON |
| --source-dir | 必填。源文件根目录（按编号子串匹配其下的项目文件夹） |
| --dest-dir | 必填。项目文件夹复制目标目录 |
| --summary-dir | 必填。投标人信息汇总表输出目录 |
| --prefix | 汇总表文件名序号前缀：`seq`(默认, Excel序号) / `folder`(文件夹前导数字) / `index`(顺序号) |
| --pipeline | pdf流水线脚本路径，默认指向 `pdf信息提取` 技能的 run_pipeline.py |
| --skip-copy / --skip-extract / --skip-finalize | 跳过对应步骤 |
| --dry-run | 只打印计划不执行 |

说明：

- 步骤2：文件夹名包含项目编号即匹配；多个匹配取第一个并提示；已存在则跳过。
- 步骤3：自动识别PDF布局——根目录/子文件夹平铺（逐个提取）、公司文件夹分组（每组取首个命中）、平铺+分组混合（两种模式分别跑后按"文件名"去重合并）。每个项目的 `投标人信息汇总.xlsx` 保存在该项目文件夹内。
- 步骤4：清理"文件名"列后缀与名称残留标签，重命名为 `项目编号-项目名称.xlsx`，加前缀复制到 --summary-dir。

## 步骤5：去重校验（可单独调用）

```powershell
python -X utf8 "<技能目录>\scripts\dedup_check.py" --folder "<汇总表文件夹>" [参数...]
```

| 参数 | 说明 |
|------|------|
| --folder | 必填。存放Excel汇总表的文件夹（自动跳过 ~$ 临时文件和查重报告自身） |
| --columns | 查重列，逗号分隔；默认 `文件名,注册地址,联系人电话,电子邮件` |
| --action | `report`(默认)仅生成报告 / `mark` 报告+在重复单元格上填色 / `remove` 报告+生成 `<表名>_去重后.xlsx`（重复值保留首条，原表不动） |
| --mark-color | 标记颜色hex，默认 `FFFF0000`（红） |

规则：**单列查重，不跨列比对**；精确匹配（去除首尾空格）；空单元格不参与。报告 `列内查重结果.xlsx` 含"查重汇总"（项目表/所属列/重复值/出现次数）与"重复明细(完整行)"两个sheet；无重复时生成"查重报告(无重复)"sheet留档。

## 注意事项

- 填充色识别依赖 openpyxl 的 fgColor.rgb，主题色（无rgb值）的标记可能识别不到——遇到可在 --colors 传入对应色值并检查源表。
- 项目编号含字母（如 `2025AFXGZ01411` 中的 Z），筛选/匹配时务必与Excel原值一致；清单JSON会打印每条的编号供核对。
- 大项目（数百PDF）提取较慢，batch_run 逐项目串行；如机器内存紧张，建议分批调用 batch_run（对清单JSON手工拆分或逐机构跑）。
- 目标目录/汇总目录已存在同名文件时：项目文件夹跳过复制；汇总表直接覆盖。
- 查重仅对行内同列完全相同的值报重；形近但不同的值（如"0551-1234567"与"0551-12345678"）不算重复，如需模糊比对请另行说明。
